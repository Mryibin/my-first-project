我来推荐几个工具，都是我常用的。

**1.Listary**

电脑上文件一多，总是有些文件不知道放哪了，虽然电脑也自带文件搜索，但很慢，我看到有人推荐everything了，所以我就不推荐了，我推荐的Listary，一款可能比everything更好用的软件.

everything还需要打开相应的软件，而Listary，双击ctrl键即可弹出检索框，输入文字即可检索相关的内容并打开，非常快捷，整个用时也不会超过5秒。

  

![](images/104_001.png)

  

**2.图片助手**

这是一个图片下载的神器，做PPT经常需要到网上下载图片，有时候需要下载很多，而这款神器就可以一键下载网页上的所有图片。是不是很赞，以后去官网抠图，不用再截图了，直接用这款软件，就可以下载官网上的所有图片。

  

![](images/104_002.jpg)

**3、Pixel Map Generator**

网址：[Pixel Map Generator](https://link.zhihu.com/?target=http%3A//pixelmap.amcharts.com/)

**这真是一个非常良心的软件，第一，免费，第二，好用，是做 PPT图表的必备！使用它非常简单就能生成好看地理图表。**

  

![](images/104_003.png)

  

**4、smallpdf**

网址：[Smallpdf.com](https://link.zhihu.com/?target=https%3A//smallpdf.com/cn)

这是一个PDF解决方法的网站，如果你经常逛一些PPT的论坛和公众号，应该对他不陌生,它可以免费解决pdf的所有问题。像PDF转化为PPT、word的都是小菜一碟，他还可以编辑PDF，还是将一个PDF分成两个，还可以加密PDF等等，非常好用。

  

![](images/104_004.png)

  

  

**5、WordArt**

**网址：** [http://WordArt.com](https://link.zhihu.com/?target=http%3A//WordArt.com)

WordArt是一个**文字云**的在线生成网站，我们可以用它一键将文字排布成任何形状。除了支持英文外，他还支持中文字体。

  

![](images/104_005.png)

  

![](images/104_006.jpg)

  

**6、** **Shape Collage Pro**

既然提到了文字云，那么有没有一种方式，可以将图片排版成各种形状的呀？

真有，那就是 **Shape Collage Pro** ，这是一个**图片拼贴制作工具**。 可以轻松制作任意形状的图片拼图，如矩形、心形、圆形、字母形状，甚至绘制自定义形状。

  

![](images/104_007.png)

  

![](images/104_008.png)

  

**7、** **图标云：bgpatterns**

网址：[Pattern maker](https://link.zhihu.com/?target=http%3A//bgpatterns.com/)

既然提到了文字云和图片云，那么接下来我在提一种图标云，用它可以轻松制作任意的图标拼接的背景。

  

![](images/104_009.png)

  

**8、BenVista PhotoZoom Pro**

Photo zoom Pro 是一款图片的放大工具。

最牛的地方就是对图片进行放大不会出现轻微马赛克的状况，能较好的保持原始图片的特色。具体怎么用，试试就知道。

  

![](images/104_010.jpg)

  

**9、markdown here**  
这是一款谷歌的插件**，强烈推荐！**

有个它再也不用担心编辑器不支持markdown语法了。它能把浏览器中的文本编辑器里的 Markdown 格式的文本转换成格式化之后的 html，并可以预先定制 css 样式。

而且也是一个跨平台神器，**比如我们可以把其它平台写好的文章直接复制到微信公众号上。**

  

![](images/104_011.png)

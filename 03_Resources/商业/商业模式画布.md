# 商业模式画布

## What — 这是什么？

商业模式画布（Business Model Canvas）是一个可视化描述、分析、设计商业模式的战略工具。它将商业模式分解为9个构建块，覆盖商业的四个核心领域：客户、产品/服务、基础设施和财务。

## Why — 为什么重要？

- 用一页纸讲清楚一个商业模式
- 帮助团队对齐对业务的理解
- 发现商业模式中的薄弱环节
- 适合快速验证和迭代商业假设

## How — 如何应用？

### 九个模块

| 模块 | 含义 | 核心问题 |
|------|------|----------|
| 客户细分 | 为谁创造价值 | 谁是我们最重要的客户？ |
| 价值主张 | 解决什么问题 | 我们为客户提供什么价值？ |
| 渠道通路 | 如何触达客户 | 客户想通过什么渠道被触达？ |
| 客户关系 | 如何维系客户 | 客户期望什么样的关系？ |
| 收入来源 | 如何赚钱 | 客户愿意为什么付费？ |
| 核心资源 | 需要什么资产 | 价值主张需要什么资源？ |
| 关键业务 | 必须做什么事 | 价值主张需要什么活动？ |
| 重要伙伴 | 谁可以帮你 | 谁是我们的关键伙伴？ |
| 成本结构 | 花在哪里 | 最重要的成本是什么？ |

### 建议使用流程

1. 先在便利贴上写下每个模块的关键点
2. 贴在画布上，团队成员讨论
3. 识别模块间的一致性和矛盾
4. 迭代修改直到逻辑自洽

## 一、商业模式的概述和基础

### 商业模式的定义

商业模式是企业从事**业务活动的利益相关者的交易结构**。商业模式回答：

- **做什么**：选择什么业务领域
- **谁参与**：哪些利益相关者
- **怎样交易**：交易方式、定价、价值分配
- **怎样组织执行**：内部组织、运营管理

### 六要素（已知 → 链接内部知识）

| 要素 | 核心问题 |
|------|----------|
| 定位 | 满足客户需求的方式 |
| 业务系统 | 利益相关者的交易结构 |
| 盈利模式 | 收入来源与方式 |
| 关键资源能力 | 支撑交易结构的核心能力 |
| 现金流结构 | 现金流入流出的时空分布 |
| 企业价值 | 未来自由现金流的贴现值 |

### 与战略、管理、营销的区分

| 概念 | 关注点 |
|------|--------|
| 商业模式 | 交易结构 |
| 战略 | 做什么不做什么 |
| 管理 | 如何执行 |
| 营销 | 如何建立品牌认知 |

## 二、交易的基本原理

### 利益主体与利益相关者

- 利益主体：独立自主参与经营活动的主体
- 利益相关者：与利益主体有利益关系的个人或组织

### 交易四要素

| 要素 | 含义 |
|------|------|
| 主体 | 谁参与交易 |
| 客体 | 交易什么 |
| 权利 | 产权使用、收益、转让 |
| 方式 | 怎么交易 |

### 交易价值、交易成本、交易风险

> **核心公式**：价值空间 = 交易价值 − 交易成本 − 交易风险
>
> 商业模式优化的本质是**扩大价值空间，减少耗散**。

**三种工具视角**：

| 工具 | 视角 | 适用场景 |

| **多棱镜** | 从多个角度分析 | 复杂问题 |
| **聚焦镜** | 聚焦核心问题 | 关键决策 |

## 八、现金流结构与企业价值

### 现金流结构

按交易利益划分的现金流入和流出在时间序列上的分布状态。

### 现金流结构三大功能

- 一价值判断
- 一价值创造

### 现金流时间分布

- 企业价值
- 资本价值
- 商业价值

### 四种类型现金流结构

| 类型 | 特点 |
|------|------|

### 资本价值

> 资本价值 = 每一年的自由现金流贴现值的现值

企业的投资价值 = 企业未来可产生自由现金流的贴现值

### 企业价值评估三步骤

- 预测未来现金流

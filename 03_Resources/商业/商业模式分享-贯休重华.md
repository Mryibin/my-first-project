# 商业模式 · 分享笔记

> 分享人：贯休 | 记录人：重华 | 来源：C立方课程体系 · 商业模式模块
>
> 核心框架：利益相关者的交易结构 — 从「造船能力」到「开船能力」的乘法思维

---

## 一、核心逻辑框架：造船能力 × 开船能力

企业能力被拆解为两大维度，且是 **乘法关系**，而非加法关系。

| 维度 | 含义 | 对应模块 |
|------|------|----------|
| **造船能力** ⚓ | 有没有船 — 赚钱的能力、价值创造空间 | 商业模式 |
| **开船能力** ⛵ | 能不能开到彼岸 — 价值兑现能力 | 战略 · 组织 · 机制 · 文化 · 资本 |

> **公式**：造船能力 × 开船能力 = 企业价值

造船能力再强，开不出去也不行；开船能力再强，船本身天花板有限，最终企业价值仍然有限。**协同抵达才是最好。**

---

## 二、商业模式的定义与六要素模型

商业模式 = 利益相关者的交易结构：谁参与、拿什么换、怎么定价、钱怎么分。

### 六要素总览

| 序号 | 要素 | 核心问题 |
|------|------|----------|
| 1 | 定位 | 用什么方式满足谁的什么需求？ |
| 2 | 业务系统 | 谁参与？什么关系？交易内容是什么？ |
| 3 | 关键资源能力 | 要让模式成立，必须有什么能力？（注意：是"需要具备"的，不是"已有优势"） |
| 4 | 盈利模式 | 钱从哪来？向谁收？按什么收？何时收？ |
| 5 | 现金流结构 | 钱在什么时间进出？时间序列上的收支排布如何？ |
| 6 | 企业价值 | 未来现金流折现到当前的值 |

### 三个评价维度

| 维度 | 目标 | 含义 |
|------|------|------|
| 交易价值 | **大** | 空间有多大 |
| 交易成本 | **小** | 足够小 |
| 交易风险 | **小** | 尽可能小 |

> 价值空间 = 交易价值 − 交易成本，并尽可能降低交易风险。

---

## 三、六要素详解

### 要素一：定位

**定义**：用什么方式满足客户的需求。

⚠️ 注意区分三类定位：
- **战略定位** = 做什么 / 不做什么
- **营销定位** = 卖什么给谁
- **商业模式定位** = 用什么方式满足需求（最核心、最稳定）

> 案例：如家 — 砍掉娱乐会议附属服务，用好地段补位，做中端价格里的好体验。

**产权拆分视角**：使用权、收益权、转让权可以拆分、剔除、减少、增加、创造。卖榨汁机 vs 开果汁店 vs 教别人开果汁店 vs 品牌加盟，是完全不同的定位。

### 要素二：业务系统

**定义**：谁参与、什么关系、交易内容是什么。商业模式的核心"利益相关者交易结构"就落在业务系统上。

**核心工具 — 业务系统图**：
- 中间：企业自身（方框）
- 外部：相关利益方（圆圈）
- 连线：交易物、信息流、资金流（不同颜色线条）

> 画图目的：发现新的价值空间（能否发展出更多元的交易内容）；发现问题（交易结构是否太复杂、是否被两头挤压）。

**常见业务系统类型**：
- 专注型（大客户模式，易被两头挤压）
- 软硬一体化
- 双边平台（互联网平台，启动难）
- 单边平台（律所、咨询，分成问题是关键）

### 要素三：关键资源能力

⚠️ **最容易出错的地方**：这是"需要具备的"能力，不是"已经具备的优势"。

**分析逻辑**：
1. 基于定位和业务系统，倒推需要什么能力
2. 盘点已有能力，找出缺口
3. 重点看"缺什么"，然后补缺口

**补充能力三方法**：
- **引入新主体**（投资方、并购）
- **换用法**（京东站长助理 → 站长）
- **外包**（苹果生产外包，但用高标准管理）

> 核心启发：专注第一性原理。苹果核心是做产品，生产可以外包，但管理标准必须极高。

### 要素四：盈利模式

**四个定性问题**：
- 收什么？（货款、服务费、订阅费）
- 向谁收？（直接顾客、供应商、第三方）
- 按什么收？（按次、按量、按效果）
- 什么时候收？（一次付清、按月、按年）

**收入来源三模型**：

| 类型 | 描述 |
|------|------|
| **M0** | 直接顾客付费给企业 |
| **M1** | 顾客 + 第三方共同付费（如杂志：订阅费 + 广告费） |
| **M2** | 纯第三方付费（如搜索引擎：用户免费，广告商付费） |

⚠️ 大部分企业是 M0，这本身没有问题，不要为了复杂而复杂。

### 要素五：现金流结构

**定义**：收入和支出在时间序列上的排布。

> 核心视角：同样一年挣 100 万，年初先收钱还是年底才收钱，天壤之别。

| 行业 | 现金流特征 |
|------|-----------|
| 科技研发 | 长期投入 → 成果出来后爆发式收入 |
| 制造业 | 先垫钱生产 → 卖掉回款 |
| 基建 | 先投入 → 细水长流回收 |
| 合同能源管理 | 先垫设备 → 按运行时间慢慢收 |

> 案例：远大中央空调从卖设备改为按运行时间收费；某机电企业改做能源改造，按节省费用百分比收费，一次投入、持续收益。

### 要素六：企业价值

**计算逻辑（两步法）**：
1. 算出每年自由现金流（利润 − 成本投入等）
2. 预估未来 5 年现金流，折现到当前

> 其他估值法：DCF、PE、PS 等相对估值法。商业模式中的定位：理解前面五要素如何量化为企业价值即可。

## 四、六要素之间的关系

六者是闭环关系，相互影响，是诊断企业问题的核心基点。

### 正向推演（顺推）

```
定位 → 业务系统 → 关键资源能力 → 盈利模式 → 现金流结构 → 企业价值
```

这是生意的正常顺序。

### 逆向诊断（反推）

```
从企业价值出发，反推哪个环节出了问题
```

可能是现金流结构有问题，根因却在定位或资源能力。

## 五、诊断工具：三镜一气

| 工具 | 作用 |
|------|------|
| **广角镜** | 视野放大，看业务系统中是否有更多交易角色和多元交易结构 |
| **多棱镜** | 挖掘深层次资源和能力，能否切割重组、聚焦业务 |
| **加速器** | 金融工具（融资等），放大价值 |

⚠️ **重要警告**：如果造船能力不够强，**加速器放大的是灾难，不是价值。**

## 六、案例要点速览

| 企业       | 核心特点            | 关键问题                              |
| -------- | --------------- | --------------------------------- |
| **盒马**   | 3km 内 30 分钟送达   | 多业态同时铺，供应链跟不上，平效高但利润薄，现金流结构不够好    |
| **如家**   | 砍配套、补地段         | 选址能力、标准化装修、会员体系是关键资源能力；通过租赁缩短回本周期 |
| **元气森林** | 代工 → 自建 → 代工+自建 | 模式多次升级，线上+线下组合                    |
| **小米**   | 老能力用到新赛道（车）     | 在新业务上补齐新的关键能力                     |
| **苹果**   | 专注产品，生产外包       | 用高标准管理外包方，专注第一性原理                 |

## 八、贯穿全文的重要提醒

1. **用词要准确**：商业模式定位 ≠ 战略定位 ≠ 营销定位，概念不能混淆。
2. **关键资源能力是"需要具备"的**，不是"优势清单"，重点看缺什么。
3. **M0 不代表有问题**，不要盲目追求复杂的盈利模式。
4. **诊断是逆向逻辑**：从企业价值反推，找到根因。
5. **乘法关系思维**：商业模式（造船）和战略（开船）缺一不可，协同才能最大化价值。

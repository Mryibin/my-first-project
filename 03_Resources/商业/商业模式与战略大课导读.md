# 商业模式与战略大课导读

> 《商业模式与战略合并大课导读》完整课程总结
>
> 核心：企业价值 = 价值创造空间 × 价值创造能力，商业模式 + 战略 + AI 三部分合并讲。

---

## 一、底层框架：造船 × 开船

- **商业模式 = 造船** — 船本身怎么样、有没有赚钱能力、能进入多大价值空间
- **战略 = 选航线** — 有限的资源往哪开、选哪片水域、怎么到达
- **组织/机制/文化/资本 = 航行保障**

> 企业价值 = **价值创造空间 × 价值创造能力**（乘法，不是加法）

商业模式很好、战略很差 → 有好船但开错方向；战略很好、商业模式很差 → 清楚去哪但船撑不到。真正健康的企业需要两边同时成立。

---

## 二、商业模式：利益相关者的交易结构

商业模式不只是"我卖什么产品"，而是：
- 谁参与？彼此什么关系？
- 谁给谁提供什么价值？谁给钱？谁承担成本？
- 利益怎么分？风险由谁承担？

评价商业模式看三个指标：**交易价值（尽可能大）、交易成本（尽可能低）、交易风险（尽可能小）**。

---

## 三、六要素模型（详见 [[商业模式六要素]]）

```
定位 → 业务系统 → 关键资源能力 → 盈利模式 → 现金流结构 → 企业价值
```

- **正向推**：做商业模式设计
- **反向推**：诊断已有企业，从企业价值反推根因

六要素真正价值不在"填表"，而在于**通过因果关系找到真问题**。

### 关键资源能力的核心提醒

问的不是"我现在有什么优势"，而是"要让定位和业务系统成立，我必须具备什么能力"。

四象限：模式需要/不需要 × 目前具备/不具备。最值得关注的是 **"模式需要，但目前不具备"**。

缺能力不等于什么都要自己干：可引入新利益方、合作、外包、投资、收购、改变内部角色。**苹果把制造外包，自己集中产品/设计/标准/用户体验/供应链管理**——关键能力不一定掌握在自己组织内部。

---

## 四、战略：真正解决什么？

### 战略的定义

> 企业在**有限资源**和**不确定未来**下，为了创造价值，做出一系列带有**放弃性**的关键选择，并把选择兑现成结果。

四个核心词：资源有限、面向未来、不确定性、**放弃**（选A就无法同时做B）。

### 战略 ≠ 愿景/目标/预算

"未来三年做到1个亿"是目标，不是战略。战略必须描述**从今天到目标之间的因果路径**。

### 战略构建五步法（详见 [[战略构建五步法]]）

1. **定方向** — 长期稳定创造什么价值
2. **选战场** — 最可能赢的细分市场（工具：[[价值棋盘]]）
3. **立胜法** — 为什么客户选我（系统性优势，非单点优势）
4. **配资源与节奏** — 钱、人、时间、管理注意力压哪里
5. **算账** — 单位经济成立吗？规模经济还是规模不经济？

### 战略管理五环

> **构建 → 解码 → 落地 → 监控 → 复盘**

- 解码：把方向翻译成年目标、关键战役、里程碑
- 落地：落进组织、人才、能力、流程、KPI
- 监控：不断问"关键假设还成立吗"
- 复盘：继续/调整/停止/退出

### 战略落地需要两个承载系统

1. **商业模式承载** — 收益、现金流、成本、风险、关键能力是否闭合
2. **组织一致性承载** — 组织、流程、人才、信息、治理能否接住战略

### 案例

- **Netflix**：方向对（DVD→流媒体），但路径不一定对（2011调价拆分导致用户流失）→ **战略方向 ≠ 战术路径**
- **西南航空**：系统优势（价格敏感短途+点对点+单一机型+快周转+简化服务），非单点便宜
- **360免费杀毒**：放弃收费收入，换新的变现结构
- **IBM/Google/科大讯飞**：同样做AI，路径不同，当时没有标准答案

### 六个战略误区（详见 [[战略的定义]]）

1. 只有大企业需要战略（错，小企业资源更少更需要取舍）
2. 所有重要事情都是战略
3. 战略太虚，赚钱最重要
4. 有财务目标就是有战略
5. 战略必须全员投票共识（错，是一号位工程+理解共识）
6. 战略只是高管的事

## 五、AI 时代的商业模式与战略

### 新增变量：数据底座

AI 时代企业要同时看：**商业模式 + 战略 + 数据底座**。

AI 真正进入企业的前提是**数据能进入系统**。数据藏在员工脑子里、写在纸上、分散在表格里，就谈不上快速校准。**运营可视化，是 AI 进入经营系统的前提。**

### 三个不等式

> 生产出来 ≠ 客户看得到 ≠ 客户需要 ≠ 愿意付钱

AI 让生产越来越不稀缺，反而更要求客户洞察、差异化、价值表达、交易设计。

### 不要做"AI装修工程"

买大模型、接API、搭知识库、上智能客服，但如果成本、交付、客户价值、企业价值都没变，那只是装修。真问题应该是：**战略目标是什么 → 最大业务卡点是什么 → AI能不能解决这个卡点？**

### 优先 AI 化的五个条件

> **高频 + 刚需 + 可量化 + 可数据化 + 可闭环**

（如电商客服、工业质检、询盘报价、智能排产）

### AI 时代战略的三个变化

- 方案变多 → 决策者的筛选能力、审美、专业判断更重要
- 验证变快 → 原型、投市场、收反馈成本下降
- 迭代变快 → 竞争窗口变短

但**一号位承担最终选择责任**没有变，AI 无法替你承担资源压错、放弃什么、失败责任。

### 案例

- **霸王茶姬**：价值空间扩大（云南→全国→海外），但门店密度高、单店GMV稀释、加盟压力增大。AI 只是止血工具，没解决战略与需求端的根本矛盾。
- **瑞幸 vs 库迪**：战略看起来一样（快速扩店+补贴+数字化+AI），但底层不同——瑞幸低价是获客工具，库迪是长期低价定位；瑞幸总部有统一用户触达，库迪用户关系沉淀在加盟商。

## 六、AI 时代专业服务的价值迁移（详见 [[判断力飞轮]]）

专业服务三层价值：
1. **技术判断** — 规则明确，最易被AI替代
2. **情境判断** — 需要进入客户具体语境，AI仍需大量上下文学习
3. **承担后果的判断** — AI无法被追责、签字、承担商业责任

**制度界面能力**：与税务系统沟通、理解政策尺度、处理非标准情况——大量属于隐性知识。

### 从供应商变成"组织器官"

企业不需要自己建银行、建物流，未来也不一定需要自己培养完整财税判断能力。如果外部机构能长期稳定承担一部分组织能力，就从**外部供应商**变成**企业的外部组织器官**，客户更换成本大幅提高。

### 判断力飞轮

> 经验编码 → 判断模型 → 更精准判断 → 客户更好结果 → 留存转介绍 → 更多客户 → 更多高质量数据 → 优化模型

关键点火装置：**经验能不能被编码**。编码前是线性增长（卖人头），编码后进入飞轮增长。

### 宽而慢 vs 窄而深

窄而深（垂直深耕）带来：获客效率更高、数据有效密度更高、替代壁垒更高。但**太窄飞轮转不起来**——关键还是资源与价值空间匹配。

完整战略必须同时设计三个变量：**深度 + 节奏 + 切换条件**。

## 七、作业要求（课程实践）

作业结构：**标的与行业分析 → 商业模式分析 → 战略分析 → 问题归因 → 找对标 → 开药方**

评分结构：行业标的10% + 商业模式20% + 战略20% + 问题归因15% + 对标15% + 药方15% + 呈现规范5%

商业模式 + 战略 + 问题归因 = 55%，真正看重的是"会不会诊断"。

问题归因要求：把问题串成因果关系（现金流差→盈利模式→交易结构→定位），收敛到真正值得解决的根因。

> 这不是一个"笔记文件夹"，这是一套符合 Second Brain 理念的个人知识管理操作系统。

## 快速入门（5分钟）

### 1. 用 Obsidian 打开这个文件夹

下载 [Obsidian](https://obsidian.md)，点击"打开文件夹作为仓库"，选择 `D:\Obsidian工作区\第二大脑`。

### 2. 认识你的知识库

| 打开这个 | 你会看到 |
|----------|----------|
| [[MOC-首页]] | 整个知识库的仪表盘，最佳起点 |
| [[MOC-个人成长]] | 个人成长相关的全部知识地图 |
| [[MOC-AI学习]] | AI学习的知识地图 |
| [[标签体系说明]] | 如何正确使用标签 |
| [[插件配置指南]] | 推荐插件和配置说明 |

### 3. 今天就开始

1. 按 `Ctrl + Shift + D` 创建今天的日报
2. 打开 `MOC-首页`，看看现有的知识网络
3. 读一篇文章后，在 `04_Notes` 创建一篇[[原子笔记原则|原子笔记]]
4. 把临时想法扔进 `00_Inbox`

## 🏷 标签体系

三个维度，每次至少选 2 个：

**领域** → `#AI` `#教育` `#商业` `#科技` `#心理` `#成长`

**类型** → `#知识` `#方法` `#案例` `#观点` `#工具`

**状态** → `#待整理` `#学习中` `#已实践` `#重要`

## ✍️ 写一篇原子笔记

每篇笔记必须回答三个问题：

| 问题 | 含义 |
|------|------|
| **What** | 这是什么？一句话说清楚 |
| **Why** | 为什么重要？值得记住的原因 |
| **How** | 如何应用？具体可以做什么 |

创建新笔记时用模板：`Ctrl + T` → 选择 `模板-原子笔记`

---

## 🔗 建立连接

**双向链接是知识管理的灵魂。** 每篇笔记至少链接 2-3 篇其他笔记。

```
写法：[[笔记名称]]
效果：#什么是第二大脑 → 点击即可跳转
```

技巧：写完笔记后，用 Backlinks 面板（右侧栏）查看哪些笔记链接到了当前笔记——这些是你的"上下文"。

## 🔄 每日工作流

### 早上（5 min）
1. `Ctrl + Shift + D` 创建日报
2. 写下今天的 3 件重要任务

### 白天（随时）
1. 读到好内容 → 扔进 `00_Inbox`
2. 有想法 → 在 `04_Notes` 创建原子笔记
3. 遇到问题 → 在日报里记录

### 晚上（10 min）
1. 复盘今天的收获
2. 整理 `00_Inbox`（每周至少1次）
3. 回顾一篇 `#重要` 标签的笔记

### 周末（30 min）
1. 清空 `00_Inbox`（所有待整理项归类或删除）
2. 更新相关 MOC
3. 检查项目进度

## 🤖 自动化建议

### 1. 自动创建每日笔记

已配置 **Daily Notes** 插件：
- 位置：`07_Daily` 文件夹
- 格式：`YYYY-MM-DD.md`
- 模板：自动套用 `模板-每日复盘`
- 快捷键：`Ctrl + Shift + D`

### 2. 自动整理 Inbox（进阶）

安装 **Dataview** 后，在首页嵌入查询：

```dataview
LIST
FROM "00_Inbox"
SORT file.ctime DESC
```

使用 **Quick Add** 插件创建一键整理脚本：
1. 安装 Quick Add
2. 创建 Macro：捕获 → 按标签分类 → 移动到对应文件夹

### 3. 使用 AI 辅助整理知识

工作流：

```
原始资料 → AI 提炼摘要 → 人工判断价值 → 创建原子笔记
```

具体步骤：
1. 把文章/论文喂给 AI（如 ChatGPT）
2. 让 AI 用"费曼学习法"的方式解释核心观点
3. AI 生成三个"延伸问题"
4. 你选择最有价值的 1-2 个观点 → 用 `模板-原子笔记` 手动写
5. 添加"我的理解"和"应用场景"（AI 无法替代的部分）

### 4. AI 辅助完善笔记

让 AI 扮演"知识管理教练"：

**Prompt 模板：**
```
我正在建设个人知识库(Second Brain)。请根据以下笔记内容，帮我：

1. 用一句话提炼核心观点（不超过30字）
2. 找出可以链接的其他概念（给出2-3个建议）
3. 提出3个值得深度探索的延伸问题
4. 指出笔记中逻辑不清晰或表述模糊的地方

笔记内容：
[粘贴你的笔记]
```

## 🎯 进阶玩法

### Level 1：养成习惯
- 每天写日报，坚持 30 天
- 每周至少创建 3 篇原子笔记
- 习得"先整理再存储"的肌肉记忆

### Level 2：建立网络
- 每篇笔记至少链接 3 篇其他笔记
- 开始创建 MOC，手动梳理知识关系
- 使用 Graph View 发现"意外连接"

### Level 3：知识输出
- 每月用知识库素材写一篇长文
- 用知识库支撑一个项目决策
- 10 分钟就能找到任何你"曾经学过"的东西

### Level 4：思维操作系统
- 知识库成为你思考的"第一现场"
- 新问题 → 搜索知识库 → 已有框架 → 快速迭代
- 跨领域连接成为你的核心竞争优势

## ⚡ 常见问题

**Q: 笔记太多会不会又变成"数字垃圾"？**
A: 关键在于质量而非数量。每篇笔记都是你"消化过的"，不是"收藏的"。宁缺毋滥。

**Q: 什么时候该整理 Inbox？**
A: 至少每周一次。如果 Inbox 超过 20 条说明积压严重，减量提质。

**Q: 标签和文件夹有什么区别？**
A: 文件夹是"物理位置"（一篇笔记只能放一个文件夹），标签是"逻辑分类"（可以打多个标签）。用文件夹做顶层结构（PARA），用标签做灵活分类。

**Q: 需要把所有旧笔记迁移过来吗？**
A: 不需要。旧笔记先留在原地，只迁移你"正在用"的部分。迁移不是搬家，是重新编辑和连接的过程。

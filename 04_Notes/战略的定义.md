# 核心观点

> 一句话总结：战略是企业在有限资源和不确定未来下，为创造价值做出一系列带有"放弃性"的关键选择，并把选择兑现成结果——战略最难的不是决定做什么，而是决定不做什么。

# 详细解释

战略的四个核心词：

| 核心词 | 含义 |
|--------|------|
| **资源有限** | 钱、人、时间、管理注意力、组织带宽都有限，不能什么都做 |
| **面向未来** | 不是准确预测未来，而是用未来想去的地方，反过来决定今天怎么选 |
| **不确定性** | 正因为未来不知道，才需要战略 |
| **放弃** | 选A就无法用同样资源同时做B，战略必然意味着放弃 |

**战略 ≠ 愿景/目标/预算**：

- "未来三年做到1个亿"是目标，不是战略
- 战略必须回答：哪些客户？哪个市场？什么产品？什么赢法？什么资源？放弃什么？怎么到？
- 战略必须描述**从今天到目标之间的因果路径**

**战略 vs 管理**：战略更多解决增长，管理更多解决效率。

# 我的理解

"放弃"是战略最反直觉也最核心的部分。大多数人做战略时都在"加法"思维——什么都想抓。但战略的本质是"减法"——资源有限，选择即放弃。

小企业尤其容易掉进"什么单都接、什么机会都试"的陷阱，结果资源高度分散。

还有一个重要认知：**不要用今天的结果评价昨天的战略**。战略失败不等于决策逻辑低质量（当时没有标准答案），偶然成功也不等于决策逻辑优秀。评价战略要看当时的假设、取舍、验证逻辑。

# 应用场景

- 制定战略时明确列出"不做什么"
- 评估战略时区分"目标"和"战略"是否被混淆
- 小企业轻量战略：定战场→看资源→明确不做什么→小规模实验→快速验证→快速迭代

# 核心观点

> 一句话总结：分析商业模式有两种路径——顺推看"生意怎么跑"，反推看"哪里出了毛病"，两条路径解决不同的问题。

# 详细解释

| 方向 | 路径 | 适用场景 |
|------|------|----------|
| **顺推** | 定位 → 业务系统 → 关键资源 → 盈利模式 → 现金流 → 企业价值 | 设计新商业模式、创业规划 |
| **反推** | 从企业价值出发，反推到现金流结构、盈利模式，找到根因 | 诊断问题、企业困境、投资分析 |

**反推的核心价值**：

症状常常出现在末端（比如现金流差），但根因在头端（定位模糊）。如果一个企业"不赚钱"：
- 直接反应：降价、砍成本（调盈利模式/现金流）
- 反推诊断：问题可能在**定位**（满足需求的方式不对）或**业务系统**（交易结构不合理）

**反推四步法**：
1. 锁定问题：哪个环节表现异常？
2. 反向追溯：这个环节由谁支撑？
3. 继续追溯：上游环节有什么问题？
4. 追到根因：通常回到定位或关键资源能力的缺口

# 我的理解

顺推是"建筑师思维"（从蓝图到建筑），反推是"医生思维"（从症状到病因）。大多数人只会顺推不会反推，导致在错误的环节反复折腾。

这和 [[造船能力与开船能力]] 有内在联系：反推往往能发现"船本身有问题"而不是"开船能力有问题"——很多企业拼命练开船技术，其实是船漏水了。

# 应用场景

- 做项目复盘时用反推找根因
- 投资尽调时从财务数据反推商业模式健康度
- 创业遇到瓶颈时，从问题处反推六要素链条

# 核心观点

> 一句话总结：第二大脑是一个外部的、数字化的个人知识管理系统，用于捕获、组织、提炼和表达你的想法。

# 详细解释

第二大脑（Second Brain）是 Tiago Forte 提出的个人知识管理方法论。核心思想是：

- 人脑适合"产生想法"，不适合"存储想法"
- 将外部信息系统地整理到数字工具中
- 通过 C-O-D-E 流程：Capture（捕获）→ Organize（组织）→ Distill（提炼）→ Express（表达）

与传统的"收藏夹"不同，第二大脑强调**主动处理**而非被动囤积。

# 我的理解

第二大脑不是要替代你的记忆，而是给你一个"思考的外部空间"。它的价值不在于存了多少，而在于你是否能随时调用和连接这些知识。

# 应用场景

- 学习新领域时快速建立知识框架
- 写作时调用过往积累的素材
- 决策时回顾历史经验教训
- 跨领域创新时发现知识之间的连接

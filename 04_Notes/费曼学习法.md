# 核心观点

> 一句话总结：如果你不能用简单的语言解释清楚一个概念，说明你并没有真正理解它。

# 详细解释

费曼学习法分为四步：

1. **选择一个概念** — 确定你要学习的内容
2. **教给一个孩子** — 用最朴素的语言解释，假设你是在教一个完全不懂的人
3. **发现知识缺口** — 当你解释不下去时，就是你还没真正理解的地方，回去重新学习
4. **简化和类比** — 用类比让概念更直观，去掉专业术语

本质上，费曼学习法是用"输出"倒逼"输入"。

# 我的理解

大多数人学习的误区是：以为"看懂了"就是"学到了"。费曼学习法的厉害之处在于它暴露了"我其实没懂"的事实。每次我试图给别人解释一个概念时，总会发现自己的理解漏洞。

# 应用场景

- 学完一个新概念后立即尝试解释给别人听
- 写原子笔记时用费曼方式检验理解深度
- 面试前用此方法复习核心知识点
- 团队分享时用简单语言讲复杂问题

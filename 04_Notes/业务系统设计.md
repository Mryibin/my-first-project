# 核心观点

> 一句话总结：业务系统是商业模式的骨架——它描述了"谁参与、怎么交易、传递什么"，设计业务系统的核心是优化利益相关者之间的交易结构。

# 详细解释

业务系统梳理四步法：

1. **明确交易角色** — 列出所有利益相关者（客户、供应商、合作伙伴、平台方等）
2. **明确交易关系** — 企业与每个利益相关者之间是什么关系？（买卖、合作、平台撮合、投资等）
3. **搞清楚交易内容** — 三个要素四类内容：
   - 三流：业务流、资金流、信息流
   - 四类：产品和服务、生产要素、经营资源、经营能力
4. **串联交易关系** — 把各利益相关者的交易关系连接成完整系统

优化视角——**三镜一加速器**：
- **广角镜**：站在整个商业生态系统的角度看
- **多棱镜**：从多个维度分析交易结构
- **聚焦镜**：聚焦核心交易环节
- **加速器**：找到撬动增长的杠杆点

# 我的理解

业务系统设计的难点不是"画出来"，而是"判断好坏"。一个好的业务系统有两个特征：
1. 交易价值 > 交易成本（每笔交易都有正净收益）
2. 系统有自我强化效应（参与方越多，系统越强）

平台模式的本质就是设计了一个"交易价值随规模增长、交易成本随规模下降"的业务系统。

# 应用场景

- 用四步法梳理现有业务，发现交易结构中的冗余和断点
- 设计新业务时先画业务系统图，再填充细节
- 对标分析时画出竞品的业务系统做对比

# 核心观点

> 一句话总结：复利的本质是"收益再投资"，不仅在金融领域适用，在学习、习惯、人际关系中同样成立。

# 详细解释

复利公式：FV = PV × (1 + r)^n

- PV：初始本金
- r：收益率
- n：时间周期

复利的三个关键要素：
1. **本金**：起点很重要但非决定性
2. **收益率**：持续小幅领先的巨大价值
3. **时间**：最重要的变量，也是大多数人最缺耐心的维度

每天进步1%，一年后是37.8倍；每天退步1%，一年后只剩0.03。

# 我的理解

知识的复利效应尤其明显：你掌握的每个概念都会成为学习下一个概念的"本金"。这就是为什么跨学科的学习者往往更有创造力——他们的"知识本金"在多个领域同时复利。

原子笔记也是复利思维：每天写一篇看似微不足道，但一年后的知识网络价值远超想象。

# 应用场景

- 每天阅读30分钟，不追求多，追求持续
- 每天写一篇原子笔记
- 投资中坚持定投而非频繁交易
- 培养好习惯，让时间做你的朋友

# 核心观点

> 一句话总结：理解商业模式的深度，本质是完成五次认知跃迁——从"卖产品"到"交易结构"、从"我赢"到"局赢"、从"填格子"到"找因果"、从"混着谈"到"分三层"、从"看利润"到"看时间"。

# 详细解释

## 五次认知跃迁

| # | 浅层理解 | → | 深层理解 |
|---|----------|---|----------|
| 1 | 卖产品（关注"卖什么"） | → | 交易结构（谁参与·怎么交易·价值怎么分） |
| 2 | 我赢（焦点企业利润最大） | → | 局赢（价值空间最大·各方可持续） |
| 3 | 填格子（六要素当清单） | → | 找因果（因果链·反推诊断） |
| 4 | 混着谈（模式/战略/组织不分） | → | 分三层（造船×选航线×航行保障） |
| 5 | 看利润（静态当期） | → | 看时间（现金流时序·复利） |

## 跃迁详解

### 跃迁 1：从「卖产品」到「交易结构」

商业模式的本质定义是**"利益相关者的交易结构"**，不是"我卖什么产品"。真正进入商业模式，要回答：谁参与、谁给谁提供价值、谁付钱、谁担成本、利益怎么分、风险谁扛。

### 跃迁 2：从「我赢」到「局赢」

判断商业模式好坏，不是看焦点企业利润最大，而是看**价值空间最大**：

```
价值空间 = 交易价值 − 交易成本 − 交易风险
```

一个让总部盈利、却让关键合作方长期亏损的模式不可持续。焦点企业利润最大化 ≠ 商业模式更好。

### 跃迁 3：从「填格子」到「找因果」

六要素不是六张独立的表，而是一条**因果链**：

```
定位 → 业务系统 → 关键资源能力 → 盈利模式 → 现金流结构 → 企业价值
```

- **顺推（正向构建）**：设计新生意时，从定位一路推到企业价值
- **反推（逆向诊断）**：分析已有企业时，从企业价值一路追问"为什么"，追到定位

症状在末端（现金流差），根因常在头端（定位偏差）。这是六要素与商业模式画布最本质的区别——画布是列清单，六要素是找病灶。

### 跃迁 4：从「混着谈」到「分三层」

商业模式、战略、组织是三个**相乘**的独立变量：

```
企业价值 = 造船（商业模式）× 选航线（战略）× 航行保障（组织/机制/文化/资本）
```

大多数人犯的错是用"修船"的方法解决"航线"的问题。分清楚是"船的问题"还是"舵手的问题"，诊断才能对症。

### 跃迁 5：从「看利润」到「看时间」

同样"一年赚 100 万"，年初收钱还是年底收钱，是两种完全不同的生意。再往深一层是复利：一个能持续运转的商业模式，每一轮交易都在强化系统而非透支系统。

# 我的理解

这五次跃迁可以压缩成四个自查维度，构成判断商业模式的完整视角：

| 维度 | 关键词 | 一句话 |
|------|--------|--------|
| 结构 | 交易结构 | 不是卖什么，是谁和谁怎么交易 |
| 系统 | 价值空间 | 不是我赢，是局赢、各方可持续 |
| 因果 | 反推诊断 | 不是填表，是从症状追到根因 |
| 时间 | 现金流+复利 | 不是当期利润，是钱的时间结构和可持续强化 |

# 应用场景

**四问自测**（随便挑一家公司，不查资料试着回答）：

1. 它的**交易结构**是什么？谁给谁提供价值、钱和风险怎么流转？
2. 它的**价值空间**有多大？有没有被牺牲的关键角色？
3. 它现在最大的问题是**哪一环**？（用反推：从财务表现追到定位）
4. 它的**现金流时序**和**复利**在哪？越做越强，还是越做越薄？

能不看笔记讲清这四问，对商业模式的理解就真正"入网"了。

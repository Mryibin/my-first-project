# 核心观点

> 一句话总结：PARA 是将所有数字信息分为 Projects、Areas、Resources、Archives 四类的组织框架，按"可操作性"而非"主题"来分类。

# 详细解释

PARA 代表四个层级：

| 层级 | 含义 | 特点 | 示例 |
|------|------|------|------|
| **P**rojects | 项目 | 有明确目标和截止日期 | 写一篇文章、完成季度报告 |
| **A**reas | 领域 | 长期持续关注的责任 | 健康、财务、职业发展 |
| **R**esources | 资源 | 感兴趣的主题资料 | AI技术、投资知识 |
| **A**rchives | 归档 | 已完成或不再活跃 | 去年的项目文件 |

核心原则：同一个信息只放在一个地方，按"最可操作"的层级放置。

# 我的理解

PARA 解决了传统文件夹"越整理越乱"的问题——不是因为文件夹不够多，而是分类维度错了。按"你要拿它做什么"来分类，比按"它是什么"更实用。

# 应用场景

- 本知识库就是按 PARA 方法组织的
- 所有新信息先进 Inbox，定期整理到 PARA 对应位置
- 项目完成后归档，不占用注意力

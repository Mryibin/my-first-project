# 标签体系说明

本知识库使用统一的标签体系，分为三个维度：

## 一、领域标签

标识知识归属的领域。

| 标签 | 描述 |
|------|------|
| `#AI` | 人工智能相关 |
| `#教育` | 教育、学习方法 |
| `#商业` | 商业、创业、管理 |
| `#科技` | 技术、工程 |
| `#心理` | 心理学、认知科学 |
| `#成长` | 个人成长、习惯养成 |

## 二、类型标签

标识笔记的内容性质。

| 标签 | 描述 |
|------|------|
| `#知识` | 概念性知识 |
| `#方法` | 可操作的方法论 |
| `#案例` | 具体案例和故事 |
| `#观点` | 观点、意见 |
| `#工具` | 工具推荐和技巧 |

## 三、状态标签

标识笔记的完善程度。

| 标签 | 描述 |
|------|------|
| `#待整理` | 原始素材，尚未加工 |
| `#学习中` | 正在研究和消化 |
| `#已实践` | 已经验证过的知识 |
| `#重要` | 高价值，需要定期回顾 |

## 使用原则

1. **每篇笔记至少包含 1 个领域标签 + 1 个类型标签**
2. **状态标签按需添加，不要全部标 `#待整理`**
3. **避免创建临时的、一次性的标签**
4. **标签用中文，便于搜索和脑图识别**

## 特殊标签

| 标签 | 用途 |
|------|------|
| `#MOC` | 标识知识地图笔记 |
| `#项目` | 标识项目笔记 |
| `#日报` | 标识每日复盘 |
| `#复盘` | 标识项目/周期复盘 |
| `#读书笔记` | 标识读书笔记 |

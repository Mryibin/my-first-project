# Obsidian 插件配置指南

## 一、核心插件（已启用）

以下插件是 Obsidian 内置的核心插件，已在配置中启用：

| 插件 | 用途 |
|------|------|
| **Daily Notes** | 一键创建每日日记，自动使用模板 |
| **Templates** | 快速插入笔记模板，保持格式统一 |
| **Backlinks** | 查看哪些笔记链接到当前笔记 |
| **Graph View** | 可视化知识图谱，发现笔记间的隐藏关系 |
| **Properties** | 笔记的元数据管理（标签、日期、来源） |
| **Outgoing Links** | 当前笔记链接到哪些笔记 |
| **Tag Pane** | 右侧栏显示所有标签的层级结构 |
| **Outline** | 文档大纲快速导航 |
| **Canvas** | 创建白板/思维导图 |
| **Bookmarks** | 收藏常用笔记快速访问 |

## 二、推荐社区插件

在 Obsidian 设置 → 社区插件 → 浏览中搜索安装：

### 必备

| 插件 | 用途 |
|------|------|
| **Dataview** | 用查询语言自动汇总笔记数据，如列出所有 #重要 标签的笔记、统计月度笔记数 |
| **Templater** | 增强版模板引擎，支持自动日期、文件标题、执行脚本等高级功能 |
| **Calendar** | 日历视图，可视化查看每日日记，点击日期即可跳转 |
| **Tasks** | 汇总所有笔记中的待办事项到统一视图 |

### 推荐

| 插件 | 用途 |
|------|------|
| **Excalidraw** | 手绘风格的白板插件，适合画架构图、流程图、思维导图 |
| **Quick Add** | 自定义快捷指令，一键执行常用操作（创建笔记、插入模板等） |

## 三、Dataview 常用查询示例

### 列出所有重要笔记
```dataview
TABLE tags, created
FROM #重要
SORT created DESC
```

### 统计学习中的笔记数
```dataview
TABLE
FROM #学习中
```

### 本周创建的笔记
```dataview
TABLE file.ctime as "创建时间"
WHERE file.ctime >= date(today) - dur(7 days)
SORT file.ctime DESC
```

### 列出所有待整理内容
```dataview
TASK
FROM "00_Inbox"
```

## 四、Templater 配置建议

安装 Templater 后，设置模板文件夹为 `06_Templates`：

1. 打开 Templater 设置
2. Template folder location → `06_Templates`
3. 开启 "Trigger Templater on new file creation"
4. 在模板中使用 `<% tp.date.now("YYYY-MM-DD") %>` 代替 `{{date}}`

## 五、快捷键建议

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+N` | 新建笔记 | 默认存在 00_Inbox |
| `Ctrl+O` | 快速打开 | 搜索文件名 |
| `Ctrl+P` | 命令面板 | 所有功能的入口 |
| `Ctrl+Shift+D` | 创建每日日记 | 需要先配置 Daily Notes 插件 |

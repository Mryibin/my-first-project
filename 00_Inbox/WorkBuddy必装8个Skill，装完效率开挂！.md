用WorkBuddy，不装Skill，那相当于买了iPhone只用来打电话。

**我从两万个skill库中，筛选出了8个神级外挂，**

**覆盖90%日常办公，直接来闭眼抄作业🌟！**

1、办公神器四件套：docx / xlsx / pptx / pdf

![](https://pic3.zhimg.com/v2-6c96864d66d8e034bea67e4a8b99deb6_1440w.jpg)

这个属于职场人无脑装，因为上班80%的破活，无非就是这些（🤫）。

在技能里直接搜索以上名称，然后点击套件，或直接安装“智能高效办公卫士”。

以前折腾1小时做个表，整理个会议纪要，做个汇报PPT，

现在一句话直接做， **真的能少干很多“格式民工”的活。**

![](https://picx.zhimg.com/v2-cf070b815784e1164b0b0b645492e2a1_1440w.jpg)

**2、让AI上网帮你干活：agent-browser**

![](https://pic3.zhimg.com/v2-e6d88f803e62de40a91454be2016ccf8_1440w.jpg)

这个我特别推荐给：每天需要查资料、搜新闻、做竞品的人。

以前你让AI查资料，还能自己点进去，现在你可以直接说：

“帮我打开这5个行业网站，整理今天最新的行业新闻，提炼成一份日报。”

它自己打开网页、搜索、抓信息、整理。

**就是给AI装了一双能上网干活的手，太爽了。**

![](https://pic1.zhimg.com/v2-70ea6ea3093ae62c0ea87d1f854467c4_1440w.jpg)

**3、AI味去除器： [humanizer-zh](https://zhida.zhihu.com/search?content_id=283080061&content_type=Article&match_order=1&q=humanizer-zh&zhida_source=entity)**

![](https://picx.zhimg.com/v2-9487435c2b1de5e713f5252742873199_1440w.jpg)

这个真的太适合现在的打工人了。

因为现在最尴尬的不是：“我不会用AI写东西。”

**而是：“老板一眼看出来这是AI写的。”**

装上 humanizer-zh，直接把内容扔进去：

“帮我把这段话改得像真人说话，去掉AI腔。”

公众号、工作邮件、汇报材料，都能用。

![](https://pic1.zhimg.com/v2-a19ef8682e1504e298a1fdcb82ebabdc_1440w.jpg)

**4、Excel秒变高级图表：smart-charts**

![](https://picx.zhimg.com/v2-1261a64ca07512b2f8b86c66cc95ebd1_1440w.jpg)

**一图胜千言** ，下回老板问你“数据怎样”的时候，

直接把Excel扔给 smart-charts：

它直接帮你把一堆密密麻麻的数字，变成老板一眼就能看懂的图。

特别适合：周报、月报、销售复盘、运营数据，真的很香。

![](https://pica.zhimg.com/v2-71bff23e6423922ae9ce26872afee762_1440w.jpg)

**5、专治“资料太长，不想看”： [Summarize](https://zhida.zhihu.com/search?content_id=283080061&content_type=Article&match_order=1&q=Summarize&zhida_source=entity)**

![](https://pic1.zhimg.com/v2-1b42fd3a6765710bf10aeb6717ab9028_1440w.jpg)

职场最痛苦的事情之一：

老板说“这个你先研究一下。”

然后甩过来一个87页PDF。

别硬看，直接扔给 Summarize：

“帮我提炼核心观点、关键数据、风险点，并告诉我哪些内容值得重点看。”

**1分钟直接提炼重点，把信息垃圾变成信息重点。**

![](https://pica.zhimg.com/v2-30595eca387d0150a20c02962b049a5c_1440w.jpg)

**6、让AI自己上班：Automation**

![](https://pic4.zhimg.com/v2-26403d53028085d62fe73f17bf71cc71_1440w.jpg)

这个甚至不用额外装，WorkBuddy自带。

**我觉得这是最容易被低估的功能。**

前面的Skill解决的是：“AI帮我干活。”

**Automation解决的是：“AI自己记得干活。”**

比如：

每天早上8点：自动抓行业新闻 → 总结 → 整理成日报。

每周五：自动读取销售表 → 分析数据 → 做图 → 生成周报。

每个月：自动整理下载文件夹 → 分类 → 清理垃圾文件。

你只需要第一次把流程设置好。

后面：不用催、不用提醒，它自己跑。

**这才叫AI打工人，你在睡觉，它在帮你打工。**

![](https://pic4.zhimg.com/v2-1e5d001a21840b81b58f15844e013797_1440w.jpg)

**7、把你每天重复干的活做成Skill： [skill-creator](https://zhida.zhihu.com/search?content_id=283080061&content_type=Article&match_order=1&q=skill-creator&zhida_source=entity)**

![](https://pic2.zhimg.com/v2-186e20a2460f19a7cce647f08fa0692b_1440w.jpg)

**这个我觉得是最有“复利”的。**

现成的 Skill 再多，也不可能刚好适合你的工作。

所以不会写代码也没关系，直接把你的工作流程告诉 AI：

“第一步干什么，第二步干什么，最后怎么交付。”

它就能帮你封装成一个专属 Skill。比如以后只需要一句：“生成本周周报。”

它就按照你的流程自己跑。 **你干一次，AI以后帮你干N次。**

比如你每周都要写周报。固定流程：

拉数据 → 分析 → 总结 → 排版 → 发老板。

别每周重新做，直接告诉 skill-creator：

“这是我每周写周报的完整流程，帮我把它做成一个Skill。”

![](https://pic1.zhimg.com/v2-615802c7cc9446dd23ba5c2eefdb42ee_1440w.jpg)

**8、最后再给你一个绝杀skill： [find-skills](https://zhida.zhihu.com/search?content_id=283080061&content_type=Article&match_order=1&q=find-skills&zhida_source=entity)**

![](https://picx.zhimg.com/v2-d0f43bd2edbd2647c3433d1882ab22d7_1440w.jpg)

SkillHub里2万多个skill，你一个个翻，翻到明年都翻不完。

**不知道该装什么Skill，先装它，它是Skill 世界里的百度，**

直接告诉它你的需求，它直接帮你匹配你最需要的skill。

![](https://pic4.zhimg.com/v2-98928ac50dc3161d4093f9c00081d7f9_1440w.jpg)

**最后来看下省时效果：**

![](https://pic3.zhimg.com/v2-79fb2cedb6335f0549f137ba323050c0_1440w.jpg)

**给你总结个简单的抄作业版本：**

*文件处理： docx / xlsx / pptx / pdf*

*上网搜资料： agent-browser*

*去AI味： humanizer-zh*

*数据可视化： smart-charts*

*自动干活： Automation*

*长资料总结： Summarize*

*打造专属Skill： skill-creator*

*寻找更多Skill： find-skills*

![](https://pic3.zhimg.com/v2-73735bc719dd82a59562e4ce2eb3119c_1440w.jpg)

让AI替你真正干活，快去试试吧

适合：已经安装 Obsidian，但不知道从哪里开始的新手。  
目标：用 30 分钟建立一个真正能用的笔记系统。

先记住一句话：

> Obsidian 就是一个“会自动建立关联的本地笔记文件夹”。

你的每篇笔记，本质上都是一个 `.md` 文本文件。即使以后不用 Obsidian，也能通过其他文本编辑器打开。

---

### 一、第一次打开：先认识“仓库”

Obsidian 把保存笔记的文件夹叫作“仓库”，英文是 Vault。

如果打开软件后出现以下选项：

- 创建新仓库
- 打开本地仓库
- 打开同步仓库

请选择“创建新仓库”。

建议这样填写：

- 仓库名称： `我的知识库`
- 保存位置：选择一个容易找到、方便备份的位置
- 例如： `D:\Obsidian\我的知识库`

不要放在系统临时目录、软件下载目录里。

一个仓库就是电脑上的普通文件夹。Obsidian 默认将笔记保存在本地，而不是自动上传云端。 [Obsidian 官方：创建仓库](https://link.zhihu.com/?target=https%3A//obsidian.md/help/vault)

### 只建一个仓库就够了

刚开始不要给工作、生活、读书分别创建仓库。多个仓库之间的笔记不方便互相链接。

建议先把所有内容放在同一个仓库里，再用文件夹和标签分类。

---

### 二、认识 Obsidian 的界面

打开仓库后，界面大致分为四部分：

### 1\. 左侧文件列表

这里显示你的：

- 文件夹
- 笔记
- 图片
- PDF
- 其他附件

如果左侧栏消失了，可以点击左上角的侧边栏按钮。

### 2\. 中间编辑区

这是写笔记的地方。

Obsidian 支持同时打开多篇笔记，每篇笔记会显示为一个标签页，操作方式类似浏览器。

### 3\. 右侧栏

常见功能包括：

- 反向链接
- 标签
- 大纲
- 笔记属性
- 局部关系图

右侧栏现在看不懂没关系，前期可以暂时收起来。

### 4\. 左侧工具栏

通常包括：

- 新建笔记
- 打开关系图
- 每日笔记
- 命令面板
- 模板等功能

具体按钮会随着启用的核心插件而变化。

---

### 三、先做这几个基础设置

点击左下角齿轮，进入“设置”。

不同版本或中文翻译可能略有差异，可以通过设置页面的搜索框查找关键词。

### 1\. 编辑器设置

进入“设置 → 编辑器”，建议：

- 默认编辑模式：实时预览
- 显示行号：开启
- 拼写检查：按需开启
- 严格换行：关闭
- 自动配对括号：开启
- 自动配对 Markdown 语法：开启

“实时预览”可以让你一边输入 Markdown，一边看到接近最终排版的效果，最适合新手。

### 2\. 文件与链接设置

进入“设置 → 文件与链接”，建议：

- 自动更新内部链接：开启
- 确认文件删除：开启
- 新建笔记默认位置：指定的文件夹
- 文件夹位置： `00-收件箱`
- 新附件默认位置：指定的子文件夹
- 附件文件夹： `附件`

“自动更新内部链接”很重要。以后重命名笔记时，Obsidian 会自动修改指向它的内部链接。 [Obsidian 官方：内部链接](https://link.zhihu.com/?target=https%3A//obsidian.md/help/links)

### 3\. 外观设置

进入“设置 → 外观”：

- 主题：选择浅色或深色
- 字体大小：调到舒服即可
- 界面字体、正文字体：初期保持默认

暂时不要折腾复杂主题和 CSS。先让笔记系统运转起来。

---

### 四、建立一个简单的文件夹结构

在左侧文件列表空白处点击右键，新建以下文件夹：

```
00-收件箱
01-每日笔记
02-项目
03-知识
04-资料
05-归档
附件
模板
```

每个文件夹的用途如下：

- `00-收件箱` ：临时想法、来不及整理的内容
- `01-每日笔记` ：每天的记录
- `02-项目` ：有明确目标和结束时间的事情
- `03-知识` ：值得长期保存的知识笔记
- `04-资料` ：文章、书籍、视频、课程等资料记录
- `05-归档` ：已经结束、暂时不用的内容
- `附件` ：图片、PDF等文件
- `模板` ：存放笔记模板

这只是一套起步结构。以后如果发现不适合，可以直接修改。

不要一开始建立几十个分类。分类过细，反而会让你每次记笔记时纠结“应该放在哪里”。

### 七、Obsidian 最重要的功能：内部链接

内部链接用来连接两篇笔记。

在刚才的笔记中输入：

```
我准备建立自己的[[读书笔记]]。
```

输入两个左方括号 `[[` 后，Obsidian 会搜索已有笔记。如果没有找到对应笔记，也可以直接创建。

按住 `Ctrl` 再点击链接，就会打开它。

### 做一次完整练习

在“Obsidian练习”中输入：

```
我最近正在阅读[[活着]]，作者是[[余华]]。
```

然后依次点击 `活着` 和 `余华` ，创建两篇新笔记。

在“活着”笔记中写：

**CODE\_BLOCK\_18**

这样，“活着”和“余华”就建立了关联。

### 链接到某个标题

```
[[活着#我的感受]]
```

### 修改链接的显示文字

```
[[活着|这本小说]]
```

它显示为“这本小说”，实际仍然链接到“活着”。

### 嵌入另一篇笔记

在链接前面加一个感叹号：

```
![[活着]]
```

这会把“活着”笔记的内容直接显示在当前笔记里。

内部链接还支持链接到标题、段落、图片和附件，详细语法可查阅 [Obsidian 官方内部链接指南](https://link.zhihu.com/?target=https%3A//obsidian.md/help/links) 。

### 八、理解“反向链接”

普通链接回答的是：

> 我链接到了谁？

反向链接回答的是：

> 谁链接到了我？

例如：

```
活着 → 余华
```

打开“余华”笔记后，右侧的“反向链接”会告诉你，“活着”这篇笔记提到了余华。

这就是双向链接的价值：你不必手动维护所有关系，Obsidian 会帮你发现某个概念在哪些地方出现过。

### 实际应用

假设你创建了以下链接：

```
《活着》让我思考[[生命的意义]]。
《钢铁是怎样炼成的》也涉及[[生命的意义]]。
```

以后打开“生命的意义”笔记，就可以通过反向链接找到提到它的两篇书籍笔记。

### 九、文件夹、链接和标签应该怎么分工

新手最容易在这里混乱。

### 文件夹：表示笔记是什么

例如：

```
03-知识
04-资料/书籍
04-资料/课程
```

一篇笔记通常只放在一个文件夹里。

### 链接：表示笔记与什么有关

例如：

```
作者是[[余华]]
主题涉及[[苦难]]和[[生命的意义]]
```

链接适合表达具体关系。

### 标签：表示当前状态或用途

例如：

```
#待整理
#进行中
#已完成
#重要
```

建议前期只使用少量状态标签。

不要给每个关键词都加标签。人物、书籍、概念等内容通常更适合做成链接。

一个实用的判断方法：

- “它是什么？”——用文件夹
- “它和谁有关？”——用链接
- “它现在是什么状态？”——用标签

当笔记逐渐变多后，不要每次都展开文件夹寻找。

### 快速打开笔记

搜索包含“余华”的笔记。

```

```

搜索带有“待整理”标签的笔记。

**CODE\_BLOCK\_31**

只搜索指定文件夹。

**CODE\_BLOCK\_32**

搜索完整短语。

### 命令面板

按：

```
Ctrl + P
```

然后输入你想执行的操作，例如：

- 新建笔记
- 移动文件
- 插入模板
- 打开关系图
- 切换阅读视图
- 打开每日笔记

记不住按钮在哪里时，直接打开命令面板搜索，是最省事的方法。

### 十一、使用每日笔记

每日笔记适合记录：

- 今天要做什么
- 今天发生了什么
- 临时想法
- 工作日志
- 学习进度
- 以后需要整理的素材

### 开启每日笔记

进入：

```
设置 → 核心插件
```

开启“每日笔记”。

然后进入每日笔记的设置，建议：

- 日期格式： `YYYY-MM-DD`
- 新文件位置： `01-每日笔记`
- 模板文件位置：稍后选择每日笔记模板

```
# 2026-07-24

- [ ] 完成最重要的工作
- [ ] 阅读30分钟
- [ ] 整理收件箱

## 今日记录

- 

## 今日收获

- 

## 今日想法

- 

## 相关笔记

- [[]]
```

每天只需要打开当天笔记，先把内容记录下来。需要长期保存的知识，再整理进正式笔记。

### 十三、认识“属性”

属性是放在笔记顶部的结构化信息，例如：

- 类型
- 状态
- 日期
- 作者
- 评分
- 是否完成

按：

```
Ctrl + ;
```

可以添加属性。

例如，一篇读书笔记可以设置：

```
---
类型: 读书笔记
状态: 已读
作者: "[[余华]]"
评分: 9
完成日期: 2026-07-24
tags:
  - 读书
---
```

不需要自己编写这段代码，也可以直接在笔记顶部的属性面板中填写。

属性适合以后统一筛选和管理笔记。新手先掌握这些常用属性即可：

- `类型`
- `状态`
- `创建日期`
- `tags`
- `aliases`

注意：同名属性在整个仓库中会使用相同的数据类型，所以名称最好保持统一。例如不要同时使用“创建日期”“建立日期”“新建时间”表达同一个意思。 [Obsidian 官方：属性](https://link.zhihu.com/?target=https%3A//obsidian.md/help/properties)

### 十四、如何插入图片和附件

最简单的方法：把图片直接拖入笔记。

Obsidian会生成类似这样的内容：

**CODE\_BLOCK\_44**

也可以直接复制图片，然后在笔记中粘贴。

普通附件链接：

```
[[资料.pdf]]
```

直接显示附件内容：

```
![[资料.pdf]]
```

建议提前在“文件与链接”中将附件位置设置为：

```
附件
```

否则大量图片可能散落在笔记文件之间。

不要随意在系统文件管理器中移动附件；如果确实要调整，优先在 Obsidian 左侧文件列表中移动。

### 十五、关系图谱应该怎么用

点击左侧“关系图谱”，可以看到笔记之间的连接。

但需要注意：

> 图谱是结果，不是目标。

不要为了让图谱看起来密集而强行添加链接。

关系图谱比较适合：

- 查看哪些笔记是知识中心
- 发现孤立笔记
- 浏览某个主题周围的内容
- 演示知识之间的关系

实际工作中，“局部关系图谱”通常比整个仓库的大图谱更有用。它只显示当前笔记周围的相关笔记。

### 十六、同步和备份不是一回事

这是最重要的安全提醒之一。

### 同步

同步的作用是让电脑和手机上的文件保持一致。

例如：

- 电脑删除一篇笔记
- 删除操作同步到手机
- 手机上的同一篇笔记也被删除

### 备份

备份是在另一个位置保存一份历史副本。即使误删、覆盖或同步出错，也能恢复。

因此：

> 同步解决“多设备使用”，备份解决“数据丢失”。

Obsidian 官方也明确提醒：同步服务不等同于可靠备份。 [Obsidian 官方备份说明](https://link.zhihu.com/?target=https%3A//obsidian.md/help/backup)

### 新手可选方案

### 方案一：只在一台电脑使用

每周把整个仓库文件夹复制到：

- 移动硬盘
- U盘
- 另一个磁盘
- 专用备份目录

备份时应复制整个仓库，包括隐藏的 `.obsidian` 文件夹。

### 方案二：Obsidian Sync

这是官方付费同步功能。

优点：

- 配置相对简单
- 支持多设备
- 支持版本历史
- 可使用端到端加密

如果选择端到端加密，务必保管好密码；官方无法帮你找回遗失的加密密码。 [Obsidian Sync 安全说明](https://link.zhihu.com/?target=https%3A//help.obsidian.md/Obsidian%2520Sync/Security%2520and%2520privacy)

### 方案三：第三方云盘

可以使用 OneDrive、Dropbox、iCloud 等，但不同系统、手机平台的支持情况不同。

注意：

- 不要同时使用两个同步工具同步同一个仓库
- 修改后等待同步完成，再关闭设备
- 避免两台设备同时修改同一篇笔记
- 即使有云同步，也要单独备份

### 十七、手机端怎么使用

在手机安装 Obsidian 后，需要把同一个仓库同步到手机。

打开仓库后，主要操作方式不变：

- 点击铅笔或新建按钮创建笔记
- 长按文件打开菜单
- 使用 `[[` 创建内部链接
- 通过侧边栏访问搜索、标签和反向链接
- 使用每日笔记快速记录

建议手机端主要承担：

- 随手记录
- 查看资料
- 补充每日笔记
- 勾选待办事项

大量整理、批量移动文件、调整系统结构，更适合在电脑上完成。

---

### 十八、社区插件先不要装太多

Obsidian 可以安装社区插件，但刚开始建议先使用核心功能一到两周。

因为插件装得太多会带来：

- 设置复杂
- 学习成本增加
- 功能互相冲突
- 启动变慢
- 更新后可能不兼容
- 把时间花在折腾系统，而不是写笔记

等你明确遇到某个问题时，再寻找对应插件。

后期常见需求包括：

- 增强模板
- 表格和数据库查询
- 看板
- 日历
- Git版本管理
- 标注PDF
- 自动整理附件

不要照着别人推荐的“必装插件清单”一次安装几十个插件。适合别人的工作流，不一定适合你。

---

### 十九、推荐的日常工作流

每天按照下面的流程使用即可。

### 第一步：快速记录

所有来不及分类的内容，先放进：

**CODE\_BLOCK\_48**

或者写进当天的每日笔记。

记录时不要纠结排版和分类。

### 第二步：定期整理

每天或每周抽出十分钟处理收件箱：

- 没价值的内容删除
- 一次性任务直接完成
- 项目内容移动到“02-项目”
- 长期知识整理到“03-知识”
- 外部材料移动到“04-资料”
- 已结束内容移动到“05-归档”

### 第三步：补充链接

整理时问三个问题：

1. 这篇笔记和哪篇旧笔记有关？
2. 它提到了哪些重要人物、书籍或概念？
3. 以后我可能通过哪个主题找到它？

然后添加少量有意义的 `[[内部链接]]` 。

### 第四步：每周回顾

每周检查一次：

- `#待整理` 的笔记
- 没完成的任务
- 正在进行的项目
- 收件箱里的临时笔记
- 最近创建但没有链接的笔记

---

### 二十、一篇好笔记应该怎么写

不要只是复制原文。尽量用自己的话回答以下问题：

**CODE\_BLOCK\_49**

一篇笔记不必很长。只要以后能看懂、能找到、能继续使用，就是好笔记。

### 二十一、新手最常见的误区

### 1\. 花很多时间设计分类

先记录，再根据真实内容逐渐调整结构。

### 2\. 一开始安装大量插件

先使用核心功能。真正遇到问题后，再通过插件解决。

### 3\. 每个词都建立链接

只链接那些值得单独积累、以后会再次使用的内容。

### 4\. 把收藏当作学习

复制文章不等于掌握知识。至少补上一段自己的总结。

### 5\. 过度追求关系图谱

链接应服务于思考，而不是服务于图谱的视觉效果。

### 6\. 频繁改主题和界面

界面只需清晰、舒服。真正重要的是笔记内容。

### 7\. 只有同步，没有备份

同步错误也可能传播到所有设备。仓库一定要有独立备份。

### 8\. 频繁重建系统

结构不完美并不影响记录。先连续使用一个月，再决定是否调整。

| 关闭当前标签页 | Ctrl + W |

设置 → 快捷键

搜索任何命令，并为它设置自己的快捷键。

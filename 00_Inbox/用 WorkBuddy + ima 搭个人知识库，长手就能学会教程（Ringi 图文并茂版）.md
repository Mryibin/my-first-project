## 用 WorkBuddy + ima 搭个人知识库，长手就能学会教程

**\* 作者：Ringi ｜ 专为小白打造的 [云原生](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=1&q=%E4%BA%91%E5%8E%9F%E7%94%9F&zhida_source=entity) 与个人 AI 知识库实战指南**

---

![](https://pic1.zhimg.com/v2-e6b40283a15d8abaefe5cfcb2c885944_1440w.jpg)

很多人一提到个人知识库，第一反应就是 [Obsidian](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=1&q=Obsidian&zhida_source=entity) 。

它当然很好：本地 [Markdown](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=1&q=Markdown&zhida_source=entity) 、双链、插件、目录、模板、图谱，玩深了以后确实很强。

但问题是，很多普通人根本不是卡在“知识库不够高级”。

他们真正卡住的是： **资料太散。**

> 微信收藏里一堆文章，腾讯文档里一堆资料，电脑文件夹里一堆 PDF， [会议纪要](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=1&q=%E4%BC%9A%E8%AE%AE%E7%BA%AA%E8%A6%81&zhida_source=entity) 到处都是，视频看完没有字幕，灵感写在备忘录里，最后谁也找不到。

这时候你让一个小白上来就学 Obsidian、Markdown、模板、双链、插件，其实很容易把人劝退。

所以如果你的主要资料都在中文办公环境里，我反而建议先看一个更适合国内用户的组合：

**✅ WorkBuddy + ima**

- **ima** 负责把资料放进知识库（微信生态直连、零门槛入库）。
- **WorkBuddy** 负责读取、整理、归类、摘要和生成 Review。
- **人（Ringi）** 负责最后判断：哪些内容值得留下，哪些只是临时素材。

这是我理解的个人知识库从 0 到 1 搭建：先不考虑直接构建一个 [复杂系统](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=1&q=%E5%A4%8D%E6%9D%82%E7%B3%BB%E7%BB%9F&zhida_source=entity) ，先让你那些散落在微信、文档、PDF、会议和视频里的资料，终于有人帮你处理第一遍。

---

## 一、为什么不是一上来就用 Obsidian

Obsidian 的优势很明显：它适合长期沉淀，适合自己搭结构，适合把知识一点点织成网络。

但它也有一个现实问题： **它更像一个“很强的仓库”。**

> **但仓库本身不会帮你整理货架。**

很多人的 Obsidian 最后没有变成第二大脑，而是变成了 **第二垃圾桶** 。网页剪藏进去，PDF 丢进去，每日笔记写进去，会议纪要塞进去。刚开始很有成就感，过一段时间就不想打开了。

原因很简单： **资料进来以后，没人做第二步处理。**

- 一条临时想法该不该保留？
- 一篇文章跟哪个项目有关？
- 一个 PDF 哪几页有用？
- 一次会议到底沉淀了什么结论？
- 一段视频内容能不能变成选题？

这些问题不解决，知识库越大，负担越重。

所以普通人搭个人知识库，第一步不要追求高级。先追求一件事： **让资料进来以后，有人帮你初步处理。** 这就是 WorkBuddy + ima 的核心价值。

## 二、这个组合到底怎么分工（系统全景架构）

![](https://pic2.zhimg.com/v2-1d2fc48bfcb5855a84f267a08e79ec53_1440w.jpg)

我把它拆成三个明确角色：

| 角色 | 负责事项 | 核心原则 |
| --- | --- | --- |
| ima | 资料沉淀、微信生态文件入库、多端云同步 | 只存不乱改，保证资料随时找得到 |
| WorkBuddy | 批量读取、多维度提炼、智能打标、生成 Review | 只做 [预处理](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=1&q=%E9%A2%84%E5%A4%84%E7%90%86&zhida_source=entity) ，不替人擅自下最终结论 |
| 人（Ringi） | 筛选价值、决策留存、内容复盘、安全把关 | 拥有最终确认权，过滤无效信息与幻觉 |

这个分工至关重要。因为很多人做知识库，一上来就想让 AI 接管全部流程——自动读取、自动分类、自动总结、自动归档、自动生成正式笔记。听起来很爽，实际很危险 ⚠️。

**因为长期知识不是格式化文本，长期知识需要判断：**

- 哪些资料值得留下？
- 哪些观点只是看起来正确？
- 哪些内容未来真的会用？
- 哪些资料只是当时觉得有用，后来根本不会再打开？

这些不能完全交给 AI。更稳的方式是：

> **WorkBuddy 负责预处理，ima 负责沉淀，人负责确认。**

这个顺序不要乱。一乱，知识库就会变成一堆 AI 生成的漂亮废话。

## 三、从 0 开始：5 分钟完成连接与 Agent 闭环

## 第一步：安装并登录 ima

1. 电脑浏览器打开 [ima - 腾讯AI知识管家](https://link.zhihu.com/?target=https%3A//ima.qq.com/)
2. 下载 Mac 或 Windows 客户端，用微信扫码登录
3. 手机端：微信搜索「IMA 知识库」小程序，用同一个微信登录

> ⚠️ **重要提醒** ：ima 和 WorkBuddy 必须用同一个微信账号登录，否则知识库读不到。

## 第二步：在 WorkBuddy 中连接 ima

1. 打开 WorkBuddy 客户端
2. 点击左侧边栏的 **「资料库」** ，选择 **「ima 知识库」**
3. 点击 **「立即前往授权」** ，微信扫码确认授权

授权完成后，WorkBuddy 将获得查看知识库列表、检索资料以及存回文件的双向闭环能力。

## 第三步：检索增强（RAG）与双向存回闭环

![](https://pic2.zhimg.com/v2-e473b9a21e084e32af5eadb8dceddf8f_1440w.jpg)

- **检索调用** ：在对话中通过 `@ima知识库` 或任务附件直接引用；
- **产物存回** ：WorkBuddy 处理完资料后，点击产物区的「上传到云端」➔ 选择「ima 知识库」，形成 **读取 ➔ 提炼 ➔ 存回** 的完整闭环。

## 四、小白第一版，只建三个知识库

很多知识库教程最大的问题，是一开始就设计得太复杂。分类越多，越容易放弃。

**第一版，牢记只建三个：**

![](https://pic3.zhimg.com/v2-b39ea93ba751cccbe89b2e66d2932b3a_1440w.jpg)

```
📂 01-资料库 ── 放外部资料（文章、PDF、报告、网页剪藏、视频字幕、会议录音）
📂 02-项目库 ── 放推进中的事项（当前公众号选题、客户项目、产品方案、技术攻关）
📂 03-输出库 ── 放你自己的成果（文章草稿、复盘总结、观点卡片、方法论沉淀）
```

**为什么只建三个？**  
因为小白第一阶段最重要的不是分类精细，而是先养成一个习惯： **资料进来以后，不要到处乱放。** 先进入一个能被 AI 读取和处理的地方。

---

## 五、第一批资料不要太多：控制在 20 条以内

很多人搭知识库，最容易犯的错误是第一天就想把所有收藏夹全倒进去。全都导进去，看起来很壮观， **但这不是搭知识库，这是把垃圾堆搬进新房子。**

第一批资料一定要少（建议 20 条以内），用来重点验证三个 [链路](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=1&q=%E9%93%BE%E8%B7%AF&zhida_source=entity) ：

1. ima 能不能把这些资料存好？
2. WorkBuddy 能不能把这些资料读出来、整理好？
3. 你看完 AI 生成的结果以后，是否真的觉得有用且愿意继续用？

## 六、连接打通后，先跑三个最小 Agent 任务

![](https://pica.zhimg.com/v2-3ff14a8dadec550e9395bdf72799eb8a_1440w.jpg)

## 任务一：整理资料库（提炼清单）

```
请读取 ima 知识库中的「01-资料库」。
帮我整理最近上传的资料，按主题分组输出。
每条资料请包含：标题、一句话摘要、核心观点、适合归入的主题、是否值得精读。
不要生成最终文章，不要替我删除、移动或覆盖任何资料。
```

## 任务二：生成项目资料包（关联聚合）

```
请读取 ima 知识库中的「02-项目库」。
围绕「我的当前项目」整理一份项目资料包。
输出：项目背景、已有资料、关键问题、可用素材、缺失信息、下一步行动。
不要替我做最终决策，不要生成正式方案。
```

## 任务三：生成内容选题（创意启发）

```
请读取 ima 知识库中的「01-资料库」和「03-输出库」。
帮我生成 10 个适合发公众号或技术社区的选题。
每个选题包含：标题、核心观点、可引用资料、适合角度、风险点。
不要直接写成完整文章。
```

## 七、正确流程：资料不是直接变文章

很多人会把 AI 知识库理解成一个“自动写作机器”：资料放进去 ➔ AI 读一下 ➔ 直接生成文章 ➔ 复制发布。

这个流程极易产出套话和空洞内容。因为：

- **资料 ≠ 观点**
- **观点 ≠ 文章**
- **文章 ≠ 可以发布的高价值内容**

**更稳的工业级生产流程应该是：**

```
资料进入 ima ➔ WorkBuddy 生成 Review ➔ 人（Ringi）筛选判断 ➔ 提炼选题 ➔ 搭建大纲 ➔ 最终成文
```

这个流程看起来多了几步，其实更省时间，因为它避免了一个最大的坑： **你发出去的东西看起来完整，但你自己并没有真正判断过。**

---

## 八、个人知识库最重要的不是“存”，是“复用”

如果资料只是存进去以后再也不看，那它只是收藏夹。

建议每周五下午做一次 **[Weekly Review](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=1&q=Weekly+Review&zhida_source=entity) 复盘** ：

![](https://pic4.zhimg.com/v2-69f53eca867bb4fb3c0238b5fcf1c701_1440w.jpg)

```
请读取 ima 知识库中本周新增资料。
帮我生成一份 weekly review。
包含：本周新增内容、重复主题、值得精读的资料、
可发展成文章的选题、需要补充的信息、下周行动建议。
不要删除、移动或覆盖任何资料。
```

这份 weekly review 才是个人知识库真正开始运转的标志：定期筛、定期看、定期用。


## 结语：第二大脑不是资料越多越好

“ [第二大脑](https://zhida.zhihu.com/search?content_id=281719334&content_type=Article&match_order=3&q=%E7%AC%AC%E4%BA%8C%E5%A4%A7%E8%84%91&zhida_source=entity) ”的核心不是把资料全塞进去，而是：

- 资料进去以后，谁来处理？
- 谁来筛选？
- 谁来复盘？
- 谁来判断它未来到底有没有用？

**WorkBuddy + ima 的核心价值：ima 负责存，WorkBuddy 负责整理，人（Ringi）负责判断。**

先让每一批进入系统的资料，都有人处理、有人筛选、有人决定是否值得沉淀，这才是个人知识库真正从 0 到 1 的开始。
